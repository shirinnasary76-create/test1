# وب‌سایت دلگشا — نسخه فارسی به‌روزشده

## فایل‌های اصلی
- `index.html`: صفحه اصلی فارسی و بخش‌های معرفی حوزه‌های صنعت، معدن، تجارت و خدمات
- `style.css`: طراحی واکنش‌گرا، منوی چهارگانه و استفاده از بنر محلی
- `script.js`: منوی موبایل، تاریخ فارسی، فرم نمایشی و رفتار منوی چهارگانه
- `README.md`: راهنمای استقرار
- `media/banner-main.png`: بنر طراحی‌شده و بارگذاری‌شده توسط کاربر

## انتشار در GitHub Pages
1. فایل ZIP را دانلود و از حالت فشرده خارج کنید.
2. فایل‌های `index.html`، `style.css`، `script.js` و `README.md` را در ریشه مخزن GitHub قرار دهید.
3. پوشه `media` را نیز کامل بارگذاری کنید؛ فایل بنر باید در مسیر `media/banner-main.png` قرار داشته باشد.
4. در GitHub روی **Commit changes** کلیک کنید.
5. در `Settings` → `Pages` شاخه `main` و پوشه `/(root)` را انتخاب کنید.
6. پس از انتشار، سایت را با `Ctrl+F5` تازه‌سازی کنید.

**مهم:** فقط فایل ZIP را در مخزن قرار ندهید؛ محتویات ZIP را استخراج و بارگذاری کنید. `index.html` باید در ریشه مخزن باشد.

## درباره محتوای وزارت صمت
این سایت یک درگاه مستقل با معرفی موضوعی صنعت، معدن و تجارت است و به وب‌سایت رسمی وزارت صمت در نشانی https://www.mimt.gov.ir/ پیوند می‌دهد. متن‌های موضوعی این صفحه خلاصه و توضیحی‌اند؛ این نسخه کپی کامل صفحات زنده وزارتخانه نیست و اخبار روز، نام مسئولان، شماره بخشنامه‌ها یا نشانی اختصاصی سامانه‌ها را جعل نمی‌کند. برای اطلاعات معتبر و به‌روز، منبع رسمی را بررسی کنید.

## ورود و ثبت‌نام
پیوند «ثبت‌نام / ورود» در هدر فعلاً به `register.html` اشاره می‌کند. برای فعال شدن آن باید صفحه `register.html` ایجاد شود یا مقصد پیوند در `index.html` تغییر کند.

## ویدیو و فرم تماس
برای ویدیو، آدرس فایل MP4 را در ویژگی `src` تگ `source` در `index.html` قرار دهید. فرم تماس فعلاً نمایشی است و برای ارسال واقعی باید به سرویس فرم یا بک‌اند متصل شود.


## تغییرات نسخه جدید
- بنر اصلی از `media/banner-main.png` بارگذاری می‌شود.
- صفحه فارسی و راست‌چین است (`lang="fa"` و `dir="rtl"`).
- نوار سفید زیر بنر حذف شده و سه منوی آبشاری سرمه‌ای برای صنعت، معدن و تجارت قرار دارد.
- ویدیوی مدیرعامل را با نام `intro.mp4` در پوشه `media/` قرار دهید.
- برای تصاویر سایت، پوشه `media/images/` و راهنمای عنوان/مسیرها در صفحه اصلی را ببینید.
- برای انتشار در GitHub Pages، محتویات این بسته را مستقیماً در ریشه مخزن و شاخه `main` بارگذاری کنید؛ سپس در Settings → Pages، گزینه `Deploy from a branch`، شاخه `main` و پوشه `/(root)` را انتخاب کنید.

**توجه:** متن‌های حوزه‌ای موجود در این قالب، محتوای عمومی و راهنمایی هستند؛ اخبار و اطلاعات زنده وزارت صمت به‌طور خودکار از سایت رسمی دریافت نمی‌شوند. برای محتوای رسمی و به‌روز، پیوند وزارتخانه در سایت قرار دارد.
